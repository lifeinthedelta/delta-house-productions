# Delta House Productions — Version 4

A rebuilt, responsive GitHub Pages website for Delta House Productions.

## Files
- `index.html` — main website
- `style.css` — all styling

## Deploy
1. Replace the files in the GitHub repository with these files.
2. Commit the changes.
3. GitHub Pages will publish the updated site.

The site is designed to work from the repository root at:
`/delta-house-productions/`

No build process is required.
